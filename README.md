## Installation

Clone this repository first

```bash
git clone https://github.com/ReinKageno/pbx-teensclub-web.git
cd pbx-teensclub-web
python3 -m venv venv
```

Create python virtual environment and activate </br>
Install all requirements from `requirements.txt`

```bash
source ./venv/bin/activate
pip install -r requirements.txt
```

You must have PostgreSQL to manage the database. To install PostgreSQL, run these command.

```bash
sudo apt install postgresql
```

This project require a specifict database. Create a database with PostgreSQL with name `pbxteensclub_db`

```bash
createdb -U postgres pbxteensclub_db
```

# Setup

### PostgreSQL

This is the `.env` template that you can use. </br>
Replace the parts enclosed inside the brackets `<>` (include the brackets) with your own data.

```env
DATABASE_URL="postgresql+psycopg://postgres:<password>@<ip>:<port>/pbxteensclub_db"
```

### User Generation

User ID is generated by system, set up `GEN_USER_ID` in `.env` file to set the maximum number allowed to generate. </br>

# How to use

> [!INFO] Experimental Project
> Currently this project is lack of interface, so you need to get done the things from `/docs/`.
> Some action may still need to do manually step-by-step.

### Create user

To create a new user, post a `/user/register` from `/docs`

### Make user as admin

Currently, using PostgreSQL is the only way to make user as admin. Find the user and set it's `is_admin` to `t`.

```postgresql
# Find which user to make as admin
SELECT * FROM server.user;

# Make it as admin
UPDATE server.user
SET is_admin = true
WHERE username = 'username';
```

> [!WARNING] PostgreSQL
> Make sure to double check the postgresql commands before run them, the action cannot be undone.
